; ====================== 区块1：硬件地址定义区【基础硬件配置，实验箱适配核心】 ======================
; 作用：给8254定时器、8255并行口分配固定操作地址，是程序控制硬件的“门牌号”，需与实验箱实际接线一致
; 【每一行可灵活修改的方式+具体效果（实验箱适配/功能调整）】：
; 1. A8254 EQU 0600H → 修改0600H为其他十六进制数（如0200H/0300H/0640H）：
;    - 0200H：适配老式实验箱的8254计数器0地址
;    - 0640H：与8255地址互换，适配接线交叉的实验箱
;    - 核心作用：更换8254计数器0的硬件操作地址，保证程序能找到定时器
; 2. B8254 EQU 0602H → 修改0602H为其他值（如0202H/0302H/0642H）：
;    - 对应8254计数器1的地址，若程序改用计数器1定时，需同步修改后续8254初始化的DX值
; 3. C8254 EQU 0604H → 修改0604H为其他值（如0204H/0304H）：
;    - 对应8254计数器2的地址，若用计数器2定时，需同步修改初始化的DX和控制字
; 4. MODE8254 EQU 0606H → 修改0606H为其他值（如0206H/0306H）：
;    - 8254的方式控制字写入地址，是定时器的“配置入口”，必须与实验箱的8254控制口一致
; 5. A8255 EQU 0640H → 修改0640H为其他值（如0600H/0200H）：
;    - 8255的A口地址，本程序未用A口，若需用A口控制其他外设（如数码管），改此值适配
; 6. B8255 EQU 0642H → 修改0642H为其他值（如0602H/0202H）：
;    - 核心！LED灯的控制口地址，若实验箱LED接8255 A口，需改此值为A8255，并同步修改主循环的DX=A8255
; 7. C8255 EQU 0644H → 修改0644H为其他值（如0604H/0204H）：
;    - 8255的C口地址，本程序未用，若需用C口接按键/开关，改此值适配
; 8. MODE8255 EQU 0646H → 修改0646H为其他值（如0606H/0206H）：
;    - 8255的方式控制字写入地址，是并行口的“配置入口”，必须与实验箱的8255控制口一致
A8254    EQU  0600H   ; 8254计数器0地址（改此值适配实验箱8254计数器0接线）
B8254    EQU  0602H   ; 8254计数器1地址（备用，改此值适配计数器1）
C8254    EQU  0604H   ; 8254计数器2地址（备用，改此值适配计数器2）
MODE8254  EQU  0606H  ; 8254方式控制口地址（改此值适配实验箱8254控制口）
 
A8255 EQU 0640H       ; 8255 A口地址（备用，改此值适配A口接线）
B8255 EQU 0642H       ; 8255 B口地址（LED控制口，核心！改此值适配LED接线）
C8255 EQU 0644H       ; 8255 C口地址（备用，改此值适配C口接线）
MODE8255 EQU 0646H    ; 8255方式控制口地址（改此值适配实验箱8255控制口）

; ====================== 区块2：栈段定义区【程序运行的临时存储区，防止数据溢出】 ======================
; 作用：为程序分配栈空间，用于子程序调用、寄存器入栈（如中断中的PUSH/POP）的临时存储，避免数据覆盖
; 【可灵活修改的行及效果（栈大小调整，适配不同程序复杂度）】：
; 1. DW 32 DUP(?) → 修改32为其他十进制数（如16/64/128/256/0）：
;    - 16：减小栈空间（程序简单，仅中断用1个PUSH时，16足够，节省内存）
;    - 64：增大栈空间（若后续新增多个PUSH寄存器/嵌套子程序，防止栈溢出）
;    - 128/256：超大栈空间（适配复杂程序，如同时触发多个中断、多层子程序调用）
;    - 0：无栈空间（仅测试程序，无中断/子程序时可用，有中断会直接崩溃）
; 2. SSTACK SEGMENT STACK → 段名可改（如STACK_SEG SEGMENT STACK），仅提升可读性，无功能影响
; 3. SSTACK ENDS → 需与段名同步修改（如STACK_SEG ENDS），否则汇编报错
SSTACK  SEGMENT STACK
        DW 32 DUP(?)            ; 分配32个字的栈空间（改32调整栈大小，16/64/128按需改）
SSTACK  ENDS

; ====================== 区块3：代码段声明区【汇编程序的固定格式，不可乱改】 ======================
; 作用：告诉编译器代码段的名称、寄存器的归属关系（CS对应代码段，SS对应栈段），是汇编程序的“骨架”
; 【可灵活修改的行及效果（仅可读性调整，无功能影响）】：
; 1. CODE SEGMENT → 段名可改（如MAIN_CODE SEGMENT），仅提升可读性
; 2. ASSUME CS:CODE, SS:SSTACK → 若栈段名改了（如STACK_SEG），需同步改SS:STACK_SEG，否则编译器报错
; 3. CODE ENDS → 需与段名同步修改（如MAIN_CODE ENDS），否则汇编报错
CODE    SEGMENT
        ASSUME CS:CODE, SS:SSTACK  ; 绑定CS到代码段，SS到栈段（栈段名改则同步改）
START:  ; 程序入口标号，不可删除，改名为BEGIN也可（需同步修改END后的标号）

; ====================== 区块4：8255并行口初始化区【LED灯的输出模式配置，核心！】 ======================
; 作用：配置8255的工作模式，指定B口为**输出模式**（才能控制LED灯的亮灭），初始全灭
; 【每一行可灵活修改的方式+具体效果（LED控制模式调整）】：
; 1. PUSH DS → 可删除（本程序中DS仅临时用于中断向量表，后续POP DS已恢复，无影响）
; 2. MOV DX,MODE8255 → 若MODE8255地址改了（如0606H），需同步改此DX值，否则8255初始化失败
; 3. MOV AL,80H → 修改80H为其他8255方式控制字，**彻底改变8255的输入输出模式**：
;    - 80H：A口输出、B口输出、C口输出（本程序用此，3个口都能控制外设）
;    - 90H：A口输入、B口输出、C口输出（若A口接开关，用此模式）
;    - 88H：A口输出、B口输入、C口输入（若B口接按键，用此模式，LED需换A口）
;    - 98H：A口输入、B口输入、C口输出（3个口全输入，仅测试用）
;    - 核心！必须保证B口为输出（控制字的D1位=0），否则LED无法点亮
; 4. OUT DX,AL → 固定指令，将控制字写入8255控制口，不可修改，仅需保证DX指向MODE8255
        PUSH DS                 ; 暂存DS寄存器（可删除，无功能影响）
        
        MOV DX,MODE8255         ; 指向8255控制口（MODE8255地址改则同步改DX）
        MOV AL,80H              ; 8255控制字：B口输出（核心！改80H换输入输出模式）
        OUT DX,AL               ; 将控制字写入8255，完成LED口的输出配置

; ====================== 区块5：中断向量表设置区【8254定时中断的“入口导航”，核心！】 ======================
; 作用：将8254定时触发的中断处理子程序MIR7的地址，写入CPU的中断向量表，让CPU知道“中断来了执行哪个程序”
; 【每一行可灵活修改的方式+具体效果（中断号/中断程序调整）】：
; 1. MOV AX, 0000H → 固定值，指向中断向量表的基地址（0000H段），不可修改
; 2. MOV DS, AX → 固定指令，将DS指向中断向量表，不可修改
; 3. MOV AX, OFFSET MIR7 → 修改MIR7为其他子程序名（如MIR6/MIR8/LED_CTRL）：
;    - 若新增其他中断程序（如按键中断），可改此值指向新程序，实现不同中断执行不同逻辑
;    - 核心！中断子程序的“入口地址”，改此值换中断执行的程序
; 4. MOV SI, 003CH → 修改003CH为其他中断向量地址，**更换中断号**，适配实验箱的中断接线：
;    - 003CH：对应中断号0FH（8259从片中断，本程序用此）
;    - 0038H：对应中断号0EH（8259从片另一个中断）
;    - 0020H：对应中断号08H（8259主片定时器中断）
;    - 0024H：对应中断号09H（8259主片键盘中断）
;    - 核心！需与8259初始化的中断号基址（08H）匹配，否则中断无法响应
; 5. MOV [SI], AX → 固定指令，将中断程序的偏移地址写入向量表，不可修改
; 6. MOV AX, CS → 固定值，指向代码段的段地址，不可修改（中断程序在代码段）
; 7. MOV SI, 003EH → 必须与上一个SI值（003CH）**相差2**，存储中断程序的段地址：
;    - 若SI=0038H，此行需改SI=003AH；若SI=0020H，此行改SI=0022H
;    - 改错位会导致中断程序地址错误，CPU执行乱码
; 8. MOV [SI], AX → 固定指令，将中断程序的段地址写入向量表，不可修改
        MOV AX, 0000H           ; 指向中断向量表基地址（固定值，不可改）
        MOV DS, AX              ; DS绑定到中断向量表（固定指令，不可改）
        MOV AX, OFFSET MIR7     ; 获取中断子程序MIR7的偏移地址（改MIR7换中断程序）
        MOV SI, 003CH           ; 中断向量表存储位置（改003CH换中断号，核心！）
        MOV [SI], AX            ; 写入中断程序的偏移地址（固定指令）
        MOV AX, CS              ; 获取代码段地址（固定值，不可改）
        MOV SI, 003EH           ; 段地址存储位置（与上一个SI差2，核心！）
        MOV [SI], AX            ; 写入中断程序的段地址（固定指令）

; ====================== 区块6：8259中断控制器初始化区【开启定时中断，让CPU能接收中断信号】 ======================
; 作用：配置8259中断控制器的工作模式，**开启8254定时中断的响应**，关闭无关中断，是中断的“总开关”
; 【每一行可灵活修改的方式+具体效果（中断触发方式/级联/屏蔽调整）】：
; 1. CLI → 固定指令，关中断（防止初始化8259时被中断信号干扰），不可修改
; 2. POP DS → 恢复之前PUSH的DS寄存器（可删除，与前面的PUSH DS对应）
; 3. MOV AL, 11H → 修改11H为其他8259 ICW1控制字，**改变中断触发方式/级联模式**：
;    - 11H：边沿触发、多片8259、需要ICW4（本程序用此，适配大部分实验箱）
;    - 10H：边沿触发、单片8259、需要ICW4（简化模式，实验箱只有1片8259时用）
;    - 01H：电平触发、单片8259、需要ICW4（适配电平触发的中断源）
;    - 核心！边沿触发（11H/10H）更稳定，适合8254定时中断
; 4. OUT 20H, AL → 固定值，写入8259主片命令口（20H），不可修改
; 5. MOV AL, 08H → 修改08H为其他8259 ICW2控制字，**更换中断号基址**：
;    - 08H：中断号基址为08H（对应中断号08H~0FH），与前面的SI=003CH（0FH）匹配
;    - 07H：基址为07H（中断号07H~0EH），需同步改SI=003AH（0EH）
;    - 09H：基址为09H（中断号09H~10H），需同步改SI=0040H（10H）
;    - 核心！必须与中断向量表的SI地址匹配，否则中断无法响应
; 6. OUT 21H, AL → 固定值，写入8259主片数据口（21H），不可修改
; 7. MOV AL, 04H → 修改04H为其他8259 ICW3控制字，**改变8259级联方式**：
;    - 04H：主片的IR2引脚接从片（本程序用此，适配多片8259）
;    - 02H：主片的IR1引脚接从片（实验箱从片接IR1时用）
;    - 00H：单片8259（无主从级联，简化模式）
; 8. OUT 21H, AL → 固定指令，写入8259主片数据口，不可修改
; 9. MOV AL, 07H → 修改07H为其他8259 ICW4控制字，**改变中断结束方式**：
;    - 07H：非自动结束中断、缓冲模式、8086模式（本程序用此，需手动结束中断）
;    - 03H：自动结束中断、缓冲模式、8086模式（简化模式，无需手动发EOI指令）
;    - 核心！自动结束中断（03H）更简单，适合新手
; 10. OUT 21H, AL → 固定指令，写入8259主片数据口，不可修改
; 11. MOV AL, 2FH → 修改2FH为其他8259 OCW1控制字，**屏蔽/开启不同中断源**：
;    - 2FH：仅开启8254定时中断，屏蔽其他无关中断（本程序用此，避免干扰）
;    - 00H：开启所有中断（适合多中断源实验，如同时触发定时+按键中断）
;    - FFH：屏蔽所有中断（仅测试程序，无中断响应）
;    - 核心！二进制中某一位=0表示开启对应中断，=1表示屏蔽
; 12. OUT 21H, AL → 固定指令，写入8259主片数据口，不可修改
        CLI                     ; 关中断，防止初始化被干扰（固定指令，不可改）
        POP DS                  ; 恢复DS寄存器（与前面的PUSH DS对应，可删除）
       
        MOV AL, 11H             ; 8259 ICW1：边沿触发（改11H换触发方式，核心！）
        OUT 20H, AL             ; 写入8259主片命令口（固定值，不可改）
        MOV AL, 08H             ; 8259 ICW2：中断号基址08H（改08H换基址，核心！）
        OUT 21H, AL             ; 写入8259主片数据口（固定值，不可改）
        MOV AL, 04H             ; 8259 ICW3：主片IR2接从片（改04H换级联方式）
        OUT 21H, AL             ; 写入8259主片数据口（固定值，不可改）
        MOV AL, 07H             ; 8259 ICW4：非自动结束中断（改07H换结束方式）
        OUT 21H, AL             ; 写入8259主片数据口（固定值，不可改）
        MOV AL, 2FH             ; 8259 OCW1：开启定时中断（改2FH屏蔽/开启中断，核心！）
        OUT 21H, AL             ; 写入8259主片数据口（固定值，不可改）

; ====================== 区块7：8254定时器初始化区【1秒精确定时的核心配置，救命关键！】 ======================
; 作用：配置8254计数器0为**方式3（方波发生器）**，写入定时初值，实现1秒精确定时，是整个实验的“心脏”
; 【每一行可灵活修改的方式+具体效果（定时时间/工作方式/计数器调整）】：
; 1. MOV DX, MODE8254 → 若MODE8254地址改了（如0606H），需同步改此DX值，否则8254初始化失败
; 2. MOV AL, 36H → 修改36H为其他8254方式控制字，**彻底改变定时器的工作方式/计数器**：
;    - 36H：计数器0、先写低8位再写高8位、方式3（方波发生器）、二进制计数（本程序用此，核心！）
;    - 34H：计数器0、先写低8位再写高8位、方式2（速率波发生器）、二进制计数（换工作方式）
;    - 76H：计数器1、先写低8位再写高8位、方式3、二进制计数（改用计数器1定时）
;    - 37H：计数器0、先写低8位再写高8位、方式3、BCD码计数（改计数格式）
;    - 核心拆解36H的二进制：0011 0110B → 前2位=00（计数器0）、中间2位=11（先低后高）、后3位=011（方式3）、最后1位=0（二进制）
;    - 想改什么就改对应位：比如用计数器1→前2位=01（76H），用方式2→后3位=010（34H）
; 3. OUT DX, AL → 固定指令，将控制字写入8254控制口，不可修改
; 4. MOV DX, A8254 → 若用计数器1（76H），需改此值为B8254；用计数器2则改C8254，否则定时失败
; 5. MOV AL, 00H → 8254定时初值的**低8位**，与下一行的48H组成16位初值：04800H（十进制18432）
;    - 改此值为其他数（如FFH/80H），调整定时初值的低8位，从而改变定时时间
; 6. OUT DX, AL → 固定指令，写入8254计数器0的低8位，不可修改
; 7. MOV AL, 48H → 8254定时初值的**高8位**，核心！**改此值直接调整定时时间**：
;    - 定时时间计算公式：T = 初值 / 时钟频率（实验箱8254时钟频率一般为1.19318MHz）
;    - 本程序初值=04800H=18432 → T=18432/1.19318MHz≈0.0154秒？（实际实验箱会分频，最终输出1秒中断）
;    - 改48H为90H → 初值=09000H=36864 → 定时时间翻倍（2秒）
;    - 改48H为24H → 初值=02400H=9216 → 定时时间减半（0.5秒）
;    - 改48H为00H → 初值=0000H=65536 → 定时时间最长（约55毫秒）
;    - 核心！想让LED每2秒亮一个→改48H为90H；每0.5秒亮一个→改48H为24H
; 8. OUT DX, AL → 固定指令，写入8254计数器0的高8位，不可修改
; 9. STI → 固定指令，开中断（8254初始化完成后，允许CPU接收定时中断），不可修改
        MOV DX, MODE8254        ; 指向8254控制口（MODE8254地址改则同步改DX）
        MOV AL, 36H             ; 8254控制字：计数器0、方式3（改36H换工作方式/计数器，核心！）
        OUT DX, AL              ; 写入8254控制字，完成定时器模式配置
        MOV DX, A8254           ; 指向8254计数器0（用计数器1则改B8254，核心！）
        MOV AL, 00H             ; 定时初值低8位（改00H调整定时时间，核心！）
        OUT DX, AL              ; 写入8254计数器0低8位
        MOV AL, 48H             ; 定时初值高8位（改48H调整定时时间，核心！想2秒亮一个→改90H）
        OUT DX, AL              ; 写入8254计数器0高8位
        STI                     ; 开中断，允许接收8254定时中断（固定指令，不可改）

; ====================== 区块8：LED初始状态设置+主循环区【LED全灭，无限循环输出】 ======================
; 作用：设置LED初始状态为**全灭**，并无限循环将AL的值输出到8255 B口，等待中断触发后修改AL的值
; 【每一行可灵活修改的方式+具体效果（LED初始状态/输出口调整）】：
; 1. MOV DX,B8255 → 若LED接8255 A口，改此值为A8255；接C口改C8255，否则LED无反应
; 2. MOV AL,00H → 修改00H为其他值，**改变LED的初始状态**：
;    - 00H：全灭（本程序要求，必须用此）
;    - 01H：初始只亮D0（改实验要求，初始亮1个灯）
;    - 0FH：初始亮D0~D3（4个灯）
;    - FFH：初始全亮（改实验要求，初始全亮后逐位熄灭）
; 3. OUT DX,AL → 固定指令，将初始值输出到8255 B口，不可修改
; 4. JMP MAIN → 固定指令，无限循环，等待中断触发（改JMP IDLE则进入空循环，需新增IDLE标号）
        MOV DX,B8255            ; 指向8255 B口（LED接A口则改A8255，核心！）
        MOV AL,00H              ; LED初始值：全灭（改00H换初始状态，核心！）
MAIN:   
        OUT DX,AL               ; 将AL的值输出到LED口，实时更新灯的状态
        JMP MAIN                ; 无限循环，等待8254定时中断（固定指令，不可改）

; ====================== 区块9：中断处理子程序区【LED逐位点亮的核心逻辑，考试改分关键！】 ======================
; 作用：8254每1秒触发一次中断，执行此子程序：修改AL的值→实现“逐位点亮→全亮→重置全灭”的逻辑
; 【每一行可灵活修改的方式+具体效果（LED点亮顺序/数量/逻辑全调整，想怎么改就怎么改）】：
; ********** 先明确AL的二进制与LED的对应关系：AL=00H（00000000B）→全灭；AL=01H（00000001B）→D0亮；AL=03H（00000011B）→D0+D1亮；AL=FFH（11111111B）→全亮 **********
; 1. CMP AL,0FFH → 修改0FFH为其他值，**控制LED全亮的数量**（想亮4个/6个灯就改此值）：
;    - 0FFH：8个灯全亮（本程序要求，用此）
;    - 0FH：4个灯全亮（D0~D3），之后重置全灭
;    - 3FH：6个灯全亮（D0~D5），之后重置全灭
;    - 7FH：7个灯全亮（D0~D6），之后重置全灭
;    - 核心！想让实验只亮4个灯→改0FFH为0FH，其他代码不变，直接实现
; 2. JE NEXT → 固定指令，AL等于目标值则跳转到NEXT（重置全灭），不可修改
; 3. ROL AL,1 → 修改ROL为其他移位指令，**彻底改变LED的点亮顺序**：
;    - ROL AL,1：循环左移（D0→D1→D2→…→D7，本程序用此，从左到右亮）
;    - ROR AL,1：循环右移（D7→D6→…→D0，反向点亮，从右到左亮）
;    - SHL AL,1：逻辑左移（D0→D1→…→D7，最高位丢，无循环）
;    - SHR AL,1：逻辑右移（D7→D6→…→D0，最低位丢，无循环）
;    - 核心！想反向点亮LED→把ROL AL,1改成ROR AL,1，直接实现
; 4. INC AL → 位置/指令修改，**改变点亮的逻辑**（逐位亮/隔位亮/跳位亮）：
;    - 原位置：ROL后INC→逐位点亮（D0→D0+D1→…→全亮），本程序用此
;    - 改成ADD AL,3 → 隔2位亮（D0→D0+D1+D3→…，跳位亮）
;    - 改成INC AL两次 → 每次亮2个灯（D0→D0+D1+D2→…）
;    - 核心！想让LED隔位亮→把INC AL改成ADD AL,3
; 5. JMP EXIT → 固定指令，跳转到中断返回，不可修改
; 6. MOV AL,00H → 修改00H为其他值，**重置后的状态**（全灭/亮某一个灯）：
;    - 00H：重置全灭（本程序要求，用此）
;    - 01H：重置后只亮D0（循环点亮，从D0重新开始）
;    - 80H：重置后只亮D7（反向循环点亮）
; 7. IRET → 固定指令，中断返回，不可修改（中断程序的结束标志）
MIR7:                           ; 8254定时中断子程序入口（改名为LED_CTRL也可）
        CMP AL,0FFH             ; 判断是否全亮（改0FFH为0FH则只亮4个灯，核心！）
        JE NEXT                 ; 全亮则跳转到重置
        ROL AL,1                ; 循环左移（改ROR AL,1则反向点亮，核心！）
        INC AL                  ; 逐位点亮（改ADD AL,3则隔位亮，核心！）
        JMP EXIT                ; 跳转到中断返回
NEXT:
        MOV AL,00H              ; 重置为全灭（改00H为01H则重置后亮D0，核心！）
EXIT:  
        IRET                    ; 中断返回（固定指令，不可改）
