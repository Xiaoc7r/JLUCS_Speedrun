; ====================== 区块1：硬件地址定义区【基础配置】 ======================
; 作用：给AD0809和实验箱I/O片选分配固定操作地址，是程序操作AD0809的“门牌号”
; 【可灵活修改的行及效果】：
; 1. IOY0 EQU 0600H → 修改0600H为其他十六进制数（如0640H/0200H），适配不同实验箱的I/O片选地址
; 2. AD0809 EQU IOY0+00H*2 → 修改00H为其他值（01H~07H），切换AD0809的模拟输入通道：
;    - 00H：通道0（对应实验箱电位器通道）
;    - 01H：通道1/02H：通道2…07H：通道7（可读取其他模拟输入信号）
;    - 也可修改*2为*1/*4，适配实验箱的地址译码方式（如部分实验箱地址步长为1/4）
IOY0         EQU   0600H       ; 实验箱I/O片选地址基址
AD0809       EQU   IOY0+00H*2  ; AD0809的操作地址（对应通道0，改00H换通道）

; ====================== 区块2：栈段定义区【程序运行栈空间】 ======================
; 作用：为程序分配栈空间，用于子程序调用、寄存器入栈的临时存储
; 【可灵活修改的行及效果】：
; 1. DW 64 DUP(?) → 修改64为其他数值（如32/128/256），调整栈空间大小：
;    - 32：减小栈空间（程序简单时够用，节省内存）
;    - 128/256：增大栈空间（适合嵌套子程序多、入栈寄存器多的场景）
SSTACK  SEGMENT STACK
        DW 64 DUP(?)            ; 分配64个字的栈空间（改64调整栈大小）
SSTACK  ENDS

; ====================== 区块3：数据段定义区【转换结果存储】 ======================
; 作用：定义全局变量`VALUE`，存储AD转换的结果，用于变量监视窗口查看
; 【可灵活修改的行及效果】：
; 1. PUBLIC VALUE → 可删除此行（仅用于多模块程序共享变量，单模块无需）
; 2. VALUE DB ? → 变量类型可改（如DW ?，存储16位转换结果，适配12位AD芯片）；变量名可改（如AD_RESULT DB ?，提升可读性）
; 3. 可新增变量：如COUNT DB 0，用于统计转换次数；AD_BUF DB 10 DUP(?)，用于存储多次转换结果
PUBLIC  VALUE             
DATA    SEGMENT
VALUE   DB ?                  ; 存储8位AD转换结果（改DB为DW适配16位AD）
DATA    ENDS

; ====================== 区块4：代码段声明区【汇编格式】 ======================
; 作用：汇编程序的固定格式，告诉编译器代码段、数据段的归属关系
; 【可灵活修改的行及效果】：无（汇编语法固定，修改会导致程序报错）
CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA  ; 绑定CS到CODE段，DS到DATA段

; ====================== 区块5：数据段初始化区【数据准备】 ======================
; 作用：将数据段的地址加载到DS寄存器，让程序能读写DATA段的`VALUE`变量
; 【可灵活修改的行及效果】：无（数据段初始化的固定语法）
START:  MOV AX, DATA
        MOV DS, AX

; ====================== 区块6：AD转换核心区【核心功能】 ======================
; 作用：启动AD0809转换→延时等待转换完成→读取转换结果→存入`VALUE`，无限循环
; 【可灵活修改的行及效果】：
; 1. MOV DX, AD0809 → 若修改了AD0809的地址，需同步修改此行（如AD0809改0640H，此行DX=0640H）
; 2. OUT DX, AL → AL的值无意义（AD0809的启动仅需写操作，改AL为任意值如00H/FFH，不影响转换）
; 3. CALL DALLY → 可更换延时子程序（如CALL DELAY_LONG，延长转换等待时间，适配低速AD芯片）
; 4. IN AL, DX → 读取转换结果，若为16位AD芯片，需新增`IN AH, DX`，读取高8位
; 5. MOV VALUE, AL → 若`VALUE`改为DW类型，需改为`MOV VALUE, AX`，存储16位结果
; 6. JMP START → 可改为JMP其他标号（如JMP LOOP_AD），实现条件循环（如转换10次后停止）
        MOV DX, AD0809          ; 指向AD0809的操作地址
        OUT DX, AL              ; 写操作启动AD转换（AL值任意，改00H/FFH不影响）
        CALL DALLY              ; 调用延时子程序，等待转换完成
        IN  AL, DX              ; 读取AD转换结果到AL
        MOV VALUE, AL           ; 将结果存入VALUE变量（改VALUE名需同步修改）
        JMP START               ; 无限循环，持续转换

; ====================== 区块7：延时子程序区【转换等待】 ======================
; 作用：通过双层循环消耗CPU时钟周期实现延时，等待AD0809完成转换（AD0809转换时间约100μs，需保证延时≥转换时间）
; 【可灵活修改的行及效果】：
; 1. MOV CX, 100H → 修改100H为其他值（如050H/200H），调整外层循环次数：
;    - 050H：减少外层循环，延时变短（需确保≥AD转换时间，否则读取错误结果）
;    - 200H：增加外层循环，延时变长（更稳定，适合低速实验箱）
; 2. MOV AX, 0800H → 修改0800H为其他值（如0400H/1000H），调整内层循环次数：
;    - 0400H：内层延时变短，总延时减少
;    - 1000H：内层延时变长，总延时增加
; 3. 可删除双层循环，改为单层循环（如仅MOV CX,0FFFFH，LOOP L1），简化延时逻辑
DALLY:  PUSH CX                 ; 保存CX寄存器，防止主循环覆盖
        PUSH AX                 ; 保存AX寄存器，防止主循环覆盖
        MOV CX, 100H            ; 外层循环计数值（改100H调整延时）
A5:     MOV AX, 0800H          ; 内层循环计数值（改0800H调整延时）
A6:     DEC AX                  ; 内层循环：AX减1
        JNZ A6                  ; AX≠0则跳回A6，继续内层循环
        LOOP A5                 ; CX减1，CX≠0则跳回A5，继续外层循环
        POP AX                  ; 恢复AX寄存器
        POP CX                  ; 恢复CX寄存器
        RET                     ; 子程序返回

; ====================== 区块8：代码段结束区【汇编格式】 ======================
; 作用：汇编程序的固定格式，标记代码段结束并指定程序入口
; 【可灵活修改的行及效果】：无（修改会导致程序无法启动）
CODE    ENDS
        END START               ; 代码段结束，指定入口为START







; ====================== 区块1：硬件地址定义区【基础配置】 ======================
; 作用：给8255和AD0809分配固定操作地址，是程序控制LED和AD的“门牌号”
; 【可灵活修改的行及效果】：
; 1. A8255 EQU 0600H → 修改0600H为其他值（如0640H/0200H），更换8255 A口地址（本程序未用，预留作输入）
; 2. B8255 EQU 0602H → 修改0602H为其他值（如0642H/0202H），更换8255 B口地址（LED显示输出口，核心修改）
; 3. C8255 EQU 0604H → 修改0604H为其他值（如0644H/0204H），更换8255 C口地址（预留）
; 4. CON8255 EQU 0606H → 修改0606H为其他值（如0646H/0206H），更换8255控制寄存器地址
; 5. A0809 EQU 0640H → 修改0640H为其他值（如0600H/0200H），更换AD0809的操作地址
; 6. B0809 EQU 0642H → 修改0642H为其他值（如0602H/0202H），更换AD0809的通道控制地址（改01H换通道）
A8255 EQU 0600H       ; 8255 A口地址（预留输入，如接开关）
B8255 EQU 0602H       ; 8255 B口地址（LED显示输出口，改此值换LED硬件地址）
C8255 EQU 0604H       ; 8255 C口地址（预留）
CON8255 EQU 0606H     ; 8255控制寄存器地址
A0809 EQU 0640H       ; AD0809转换启动/结果读取地址
B0809 EQU 0642H       ; AD0809通道控制地址（改此值换AD通道）

; ====================== 区块3：8255初始化区【LED显示配置】 ======================
; 作用：配置8255的工作模式，指定A口输入、B口输出（适配LED显示的输出需求）
; 【可灵活修改的行及效果】：
; 1. MOV AL, 90H → 修改90H为其他8255控制字，更换输入输出模式：
;    - 90H：A口输入、B口输出、C口输出（本程序用此模式）
;    - 80H：A口输出、B口输出、C口输出（若A口也需控制外设）
;    - 98H：A口输入、B口输入、C口输出（若B口需读取数据）
START: 
    MOV DX, CON8255  ; 指向8255控制寄存器
    MOV AL, 90H      ; 8255控制字：A口输入，B口输出（改90H换工作模式）
    OUT DX, AL       ; 将控制字写入8255，完成初始化

; ====================== 区块4：AD转换+LED显示主循环区【核心功能】 ======================
; 作用：循环执行“设置AD通道→启动转换→延时等待→读取结果→LED显示”，实现实时转换+显示
; 【可灵活修改的行及效果】：
; 1. MOV AL,01H → 修改01H为其他值（00H~07H），切换AD0809的模拟输入通道（同基础实验）
; 2. OUT DX,AL → 若B0809地址修改，需同步修改DX的值
; 3. MOV DX, A0809 → 若A0809地址修改，需同步修改此行
; 4. OUT DX, AL → AL值无意义（AD启动仅需写操作，改00H/FFH不影响）
; 5. CALL DELAY → 可更换延时子程序（如CALL DELAY_SHORT，加快转换/显示速度）
; 6. IN AL, DX → 读取AD结果，若为16位AD，需新增IN AH,DX读取高8位
; 7. MOV DX, B8255 → 若B8255地址修改，需同步修改此行
; 8. OUT DX,AL → 若LED为共阳极，需改为MOV AL,NOT AL后再输出（反转电平，适配共阳极LED）
; 9. JMP MI → 可改为JMP其他标号，实现条件循环（如转换50次后停止）
MI:
    MOV DX,B0809
    MOV AL,01H       ; AD通道控制字（改01H换AD输入通道）
    OUT DX,AL        ; 设置AD0809的输入通道
	
    MOV DX, A0809    ; 指向AD0809转换地址
    OUT DX, AL       ; 启动AD转换（AL值任意）

    CALL DELAY       ; 延时等待转换完成（改延时子程序调整等待时间）
    IN AL, DX        ; 读取AD转换结果到AL

    MOV DX, B8255    ; 指向8255 B口（LED显示口）
    OUT DX,AL        ; 将转换结果输出到LED显示（共阴极直接输出，共阳极需先取反）
    JMP MI           ; 无限循环，持续转换+显示

; ====================== 区块5：延时子程序区【转换等待+显示速度】 ======================
; 作用：实现软件延时，既等待AD转换完成，又控制LED显示的刷新速度
; 【可灵活修改的行及效果】：
; 1. MOV CX,0FFFFH → 修改0FFFFH为其他值（如0F000H/05000H），调整延时长度：
;    - 0F000H：延时变短，转换/显示速度加快（需确保≥AD转换时间）
;    - 05000H：延时更短，速度更快（注意：过短会导致读取错误结果）
;    - 01000H：极短延时，适合高速AD芯片
; 2. 可改为双层循环（如基础实验的DALLY子程序），实现更长延时
DELAY:             
    PUSH CX          ; 保存CX寄存器
    PUSH AX          ; 保存AX寄存器（可删除，本程序内层无AX操作）
    MOV CX,0FFFFH    ; 延时计数值（改0FFFFH调整转换/显示速度）
L1: LOOP L1          ; CX减1，CX≠0则跳回L1
    POP AX           ; 恢复AX寄存器（可删除）
    POP CX           ; 恢复CX寄存器
    RET              ; 子程序返回

; ====================== 区块4：AD转换+查询等待核心区【核心功能】 ======================
; 作用：启动AD转换后，通过查询8255 A口的最高位（AD转换完成标志），等待转换完成后读取结果
; 【可灵活修改的行及效果】：
; 1. MOV AL,01H → 修改01H换AD通道（00H~07H）
; 2. TEST AL,80H → 修改80H为其他掩码（如40H/20H），更换查询的标志位：
;    - 80H：查询A口最高位（D7）作为转换完成标志（核心修改，需匹配硬件接线）
;    - 40H：查询A口D6位；20H：查询D5位（根据实验箱的AD标志位接线调整）
; 3. JNZ X1/JZ X2 → 可交换跳转条件（JZ X1/JNZ X2），适配标志位的高低电平（如标志位为低电平表示完成）
; 4. 可新增超时判断（如添加CX循环，查询次数超过阈值则退出，避免死循环）
X3: 
    MOV DX,B0809
    MOV AL,01H       ; AD通道控制字（改01H换AD输入通道）
    OUT DX,AL        ; 设置AD0809的输入通道
    MOV DX, A0809    ; 指向AD0809转换地址
    OUT DX, AL       ; 启动AD转换（AL值任意）
X1: 
    MOV DX,A8255     ; 指向8255 A口（读取AD转换完成标志）
    IN AL,DX         ; 读取A口的标志位状态
    TEST AL,80H      ; 检测最高位（D7）是否为1（改80H换查询的标志位）
    JNZ X1           ; 标志位为1（转换中），继续查询
X2:
    MOV DX,A8255     ; 再次读取标志位，确认转换完成（可选，可删除）
    IN AL,DX         
    TEST AL,80H      ; 再次检测标志位
    JZ X2            ; 标志位为0（转换完成），退出查询

; ====================== 区块5：LED显示输出区【结果显示】 ======================
; 作用：读取AD转换结果并输出到8255 B口的LED显示
; 【可灵活修改的行及效果】：
; 1. IN AL,DX → 若AD地址修改，需同步修改DX的值
; 2. OUT DX,AL → 共阳极LED需先取反（MOV AL,NOT AL），再输出
; 3. JMP X3 → 可改为条件循环，实现有限次转换
    MOV DX,A0809

; ====================== 区块6：AD转换主循环区【中断触发】 ======================
; 作用：循环启动AD转换，通过短延时避免多次触发中断，等待中断信号触发后在子程序中处理结果
; 【可灵活修改的行及效果】：
; 1. MOV AL,01H → 修改01H换AD通道（00H~07H）
; 2. CALL DELAY → 修改延时子程序的计数值，调整中断触发的间隔（避免重复中断）
; 3. JMP AA1 → 可改为条件循环，实现有限次转换
AA1:
    CLI                 ; 关中断，防止启动转换时触发中断
    MOV DX,B0809
    MOV AL,01H           ; AD通道控制字（改01H换AD输入通道）
    OUT DX,AL            ; 设置AD通道
    MOV DX, A0809 
    OUT DX, AL           ; 启动AD转换
    CALL DELAY           ; 短延时，避免单次转换触发多次中断（改延时调整间隔）
    STI                 ; 开中断，等待转换完成的中断信号
    JMP AA1              ; 无限循环，持续启动转换

; ====================== 区块7：中断处理子程序区【结果读取+显示】 ======================

; 3. OUT DX,AL → 共阳极LED需先取反（MOV AL,NOT AL），再输出

; ====================== 区块8：延时子程序区【防重复中断】 ======================
; 作用：短延时避免单次AD转换触发多次中断，控制中断响应的频率
; 【可灵活修改的行及效果】：
; 1. MOV CX,0FFFH → 修改0FFFH为其他值（如0F00H/01000H），调整延时长度：
;    - 0F00H：延时更短，中断响应更快
;    - 01000H：延时更长，避免重复中断更彻底

    PUSH AX
    MOV CX,0FFFH        ; 延时计数值（改0FFFH调整防重复中断的延时）

    POP AX
    POP CX
    RET
