### 1.1 常规路线与吉大现状：
在讨论到底该保研、考研、留学、考公还是直接就业以前，我们最好先把吉大的真实情况摆在桌面上。

#### 国内升学

首先是**国内升学**，泥吉是绝对的考研大校，或者可以称之为向上冲刺的升学跳板。

提到考研前我们必须要说保研，保研率对于cs类工科来说，只能用幽默评价，甚至打不过很多的京区211。26年也出现大面积保研比例下滑的趋势，某学院比例纯硕士一下从15.6%到13.2%，卡在这2%的学生名单一公布直接没招了，要么百日极限冲刺考研，要么无实习俯冲就业。

在这种情况叠加泥吉的就业氛围很差的前提，造就了泥吉如今“考研氛围浓”的最终体现。学校整体学习氛围不差，但就业氛围相对弱很多，尤其低年级阶段，大多数人并没有很强的自学、项目和实习意识，最自然的路径就是跟着培养方案上课考试卷绩点。等到了大三保研无望以后，考研就成了阻力最小、信息最多、身边人也最多的一条路。

#### 出国留学认可度

然后是**出国留学认可度**，这方面吉大的认可度其实相当不错。

列举 2024 届本科生数据，共有 556 人境外留学，其中 445 人进入 QS 前 100 高校，占 80.04%；去向里包括新国立、南洋理工、港大、港中文、帝国理工、UCL 等。当然，留学本身是另一套游戏，资金成本、地区选择、项目类型、回国认可度都要单独算账，泥吉的门槛和分数策略是很可以的，这里我们后面再展开。

#### 就业认可度

最后是**就业认可度**，真没必要天天刷点什么次9末9争霸赛，闹得麻麻的，真找个班上就会发现哪里来的那么多规矩，就是及格表现的一个985。

甚至对于一些老登，他会把吉大归类为印象中十多年前稳定前十的级别，基本上98%的情况也不会卡吉大，更不会有什么山川吉里山川在前能进去，但是泥吉进不去的情况。但可能这里小东西会问了，啊呀那不是还有2%嘛，这里点名阿里卡23所目标院校，以及类似极少数头部量化的情况，这种确实没有办法，但基本不影响常规就业。对于**大部分互联网、国央企、银行、研究所、普通科技公司**来说，学历这一关基本都够用。

#### 综合来看

综合来看，泥吉性价比极高，这块牌子足够你继续往下玩，不会成为那个最先卡死你的变量。然后值得一提的是泥吉极优秀的校友人脉资源，吉人天下这一块真不是吹的，你可以在世界上的任何一个犄角旮旯发现怎么这也有曾经的学长学姐。

### 1.6 本科就业

由于我自己是选择了本科就业，言辞文笔肯定要更偏向本科就业一点。在现在快速迭代的AI时代前提下，我真心认为倘若早早醒悟，早早脱离学校的象牙塔，选择本科就业就逃出来，这是一个高性价比极高的选择。

注意，这里我说的是逃。因为哪怕你选择考研读研也远远不是终点，在2026秋招今天的现状下，9硕的就业人数就已经远远高于9本就业人数了，读一个研究生，凑一个双9在现在也没有什么稀缺性可言。大部分双9本硕出来依旧是跟本科生抢着干开发，能否拿到好工作还极大程度取决于导师放不放实习，比起本科的无忧无虑，读了研反而可能会受众多约束。甚至在如今，已经被卷到有了一些大厂开发必须要硕士门槛的趋势，现在的环境根本不缺人，往后毕业人数越来越多，只能是一年比一年差，趁着本科完全能就业就逃出去就业，相对性价比极高。

当然，读研是可行的，读研比起本科也一定是进步的，但是真正考虑的是这份代价是否值得。我觉得，至少能不假思索列出几点去读研究生的目的，考虑去读研才有意义。或完全确定规划了以后的方向就是大模型就是算法，或早早就想准备央国企，或者家里能养一辈子还想再潇洒两年，什么是为了挽回高中的遗憾，都没问题。而不是说别人都读研，那我也读研吧，去怀着做题区的思维无谓的卷学历，卷到最后的最后，我们到底是为了什么呢。

以吉大计算机本科就业薪资和就业去向来说，绝大部分都是选择搞开发，前端后端测开运维，少数选择c系语言走硬件搞嵌入式。

薪资来说可以粗略的几档吧，互联网中大厂年包基本稳拿35w ~ 80w，选择传统制造业的一般也稳定拿20w ~ 45w。走央国企一般就是12w ~ 35w。然后哪怕完全不懂就业完全混了四年，只要努力找工作了往往也能靠学历有小厂兜底，薪资就不定了，可统计样本很少。这里重点要注意的是工作强度，强度从10-6-5到9-11-6不等，央国企没钱，但胜在轻松稳定。
