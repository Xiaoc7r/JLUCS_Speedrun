# JLUCS_Speedrun

这是一篇吉大计算机就业导向的全方位攻略，也是对自己大学坎坷就业成长生涯里的一个纪念。

早早暑期转正了，目前正躺在家中体验秋招，享受本科人生暑假里合法 gap 的最后一年。

闲暇时突然想给后来者留点东西，所以这也是一份献给吉大学弟学妹们的礼物。倘若对后来者的就业生涯有一丝一毫的帮助，对我都是极大的鼓励和慰藉。

最后，写这篇攻略也是为了感谢一路上帮助过我的学长学姐和众多就业前辈，感激涕零，无以言表，谨以此回馈。

## 前言

只看结果，我的这条本科就业道路似乎还算顺利，但实际上我只是一个放弃考研被逼无奈的就业速通选手，回望这半年来的坎坷歧途，更是一把辛酸泪。

有一次我偶然把找实习的过程发到社媒上监督自己，但竟然会有极多泥吉本科、硕士华五上岸的师兄来问我怎么去准备实习，问我要不要向下去走测试运维？

这件事对当时的我冲击极大，我原本也一样，以为继续读研自然会更好。但真正和这些前辈交流后才恍然大悟，学历学历归根到底只算一张入场券，所谓上岸，更是层层滤镜之下宏观延迟就业的美丽谎言。

吉大的同学从不缺乏学习能力，大家真正缺少的只是一套足够具体的就业视角。

因此，这篇攻略我更想从一个吉大普通本科生亲身经历的视角，讨论一个真正的本科就业的选择，路线，答案，以及如何去做出当下的最优解。

### 1.1 吉大现状 && 常规路线：
在讨论到底该保研、考研、留学、考公还是直接就业以前，我们要先把吉大的真实情况摆在桌面上。

#### 国内升学

首先是**国内升学成果**，泥吉是绝对的**考研大校**，或者可以称之为向上冲刺的升学跳板，升学结果年年宣传，基本都不错。

提到考研前我们必须要说保研，保研率对于cs类工科来说只能用幽默评价，甚至打不过很多的京区211。26年也出现大面积保研比例下滑的趋势，计院比例纯硕士一下从15.6%到13.2%，卡在这2%的学生名单一公布直接没招了，要么百日极限冲刺考研，要么无实习俯冲就业。

在这种保研情形烂完的情况，叠加泥吉的就业氛围很差的前提，自然就造就了泥吉如今所谓**考研氛围浓**的最终体现。吉大整体学习氛围相当不差，但就业氛围相对非常非常弱，非理工科专项大学，地域又毫无优势。

尤其在低年级阶段，大多数人并没有很强的自学、项目和实习意识，最自然的路径就是跟着培养方案上课考试卷绩点。等到了大三保研无望以后，考研就成了阻力最小、信息最多、身边人也最多的一条路。

#### 本科就业

然后是直接**本科就业认可度**，这方面刚入学的小东西真没必要天天刷什么次9末9争霸赛感觉闹得麻麻的，真找个班上就会发现哪里来的那么多规矩，都是985，985之间差距很低，归根到底一个门槛而已，泥吉就是及格表现的一个985。

基本上98%的情况不会卡吉大，更不会有什么山川吉里山川在前能进去，但是泥吉进不去的情况。但可能这里小东西会问啊呀那不是还有2%嘛，这里点名阿里去卡23所目标院校，以及类似极少数头部量化的情况，这种确实没有办法，但基本不影响常规就业。

对于**大部分互联网、国央企、银行、研究所、普通科技公司**来说，学历这一关基本都够用。甚至对于一些老登来说，他会潜意识把吉大归类为印象中十多年前稳定前十如今稍逊的级别，吃一波历史红利。

但是就业总体成果来说，泥吉只能说拉的非常彻底，拉到学院根本不敢公开被骂的幽默程度，很大一部分原因就是因为泥吉糟糕的就业氛围，和学校本身对学生就业的完全不作为导致的。绝大部分都是考研失败留校登记个科研助理，剩下很多也去byd一汽这种学历公司。

这里举个例子，北邮是211，但是在计算机就业层面一般比泥吉985的认可度是要高的。因为他们都有就业为主流的一种的实习氛围，这在泥吉内部是无法想象的，如此也导致互联网企业在哪怕卡985的情况也都会记着把北邮也带上，阿里卡23所院校卡的也是泥吉，但北邮是赫赫在榜的。

### 1.2 是否选择升学
采访了很多吉大本华五硕的师兄，以及海量吉大本硕的师兄。

首先可以先假设一下如果选择吉大内考研，最后成果怎么样。

和考研同级院校相比来说都是非常不错的，考本校难度吉大不高，向上考也成果显著。因为吉大本身就不差，学习氛围浓厚，选择考研的人数也极多，久而久之已经形成了一套比较成熟稳定的生态。想找个一起考研的室友，也比找个一起刷实习的舍友容易的太多太多。

**这里以吉大计软院为例，假设一个班35个人，基本能有20个人选择考研。然后保研，留学，本科就业一起去抢占剩下的15个。**

吉大本科平台向上考是有很大的操作空间的。只要初试分数足够也不会被卡，往华五中九等强势 985 冲都是一条非常正常的路线。举软院在 2026 年官方介绍里直接给出的说法：**本科生中约 30% 左右被保送或考取到北京大学、清华大学、中国科学院等院校研究生。**。总而言之，仅以上岸成功率为例，吉大考研无论如何都是很不错的一类选择，不用为此过于焦虑和担心。

但是，这里我们要问清楚下定决心选择考研本身的一种正确性。吉大很适合考研，和你适不适合考研，是两件完全不同的事情。

根据对师兄们的采访后，我们选择考研正确性的目的往往只剩下两种：

1. 一是以后就想去一些**学历门槛较高的岗位**，想进入研究所、央国企、部分算法岗、AI 深度研究相关岗位。

2. 二是本科玩爽没招了，需要缓解两年就业时间刷新应届，那么考研都可能是一种重新洗牌的机会。

这里一定一定要分清楚一件事：**读研本身不是目的和重点。** 。这是我最想最想强调的。因为太多吉大同学选择考研，仅仅就是因为身边的人都在考，保研又没保上，就顺着惯性继续考研。高中做题考大学，大学继续做题考研究生，整个过程非常丝滑。但现在的幽默形势就是 9 硕就业人数已经远远大于 9 本了，然后本来本科搞得开发全部缓到研究生卷。国家机器借此完美达到了宏观延迟就业的目的，你不读研谁赚你的钱啊，你读个研，就能让很多岗位出来了，可代价是什么呢？

问题就在这里。如果你和大多数人一样，最后仍然需要学黑马 Java 后端去和本科生抢后端，那读三年研究生究竟给你带来了什么？

是啊，硕士学历很有价值，它能扩大一部分岗位选择，也能让你进入一些本科进不去的单位，但代价同样非常明确：**两到三年的时间成本，以及导师、论文、毕业要求对实习自由度的限制，有可能损耗远远大于本科就业本身。** 。尤其在计算机和AI这个变化极快的行业里，三年已经是天翻地覆的变化了，gpt出现才不到四年，这完全不夸张，

### 1.3 细说本科就业选择
**由于我自己是选择了本科就业，言辞文笔肯定要更偏向本科就业一点。**

因为在现在快速迭代的AI时代前提下，我真心认为倘若早早醒悟，早早脱离学校的象牙塔，选择本科就业就逃出来，这一定是一个高性价比极高的选择。

注意，这里我说的是逃。因为哪怕你选择考研读研留学也远远不是终点，在2026秋招今天的现状下，9硕的就业人数就已经远远高于9本就业人数了，读一个研究生，凑一个双9在现在也没有什么稀缺性可言。大部分双9本硕出来依旧是跟本科生抢着干开发，能否拿到好工作还极大程度取决于导师放不放实习，比起本科的无忧无虑，读了研反而可能会受众多约束。

甚至在如今，已经被卷到有了一些大厂开发也必须要硕士门槛的趋势，因为现在的环境根本不缺人，在近些年就业形势不断下滑的过程，趁着本科能就业就逃出去就业工作三年相对性价比极高。 **读研什么时候都可以去读，也绝不止考研的一条道路，但本科应届生的机会确实只有一次。**

以吉大计算机本科就业薪资和就业去向来说，绝大部分都是选择传统 java / go 去企业搞后端开发，然后少数突击选择了前端测开运维，另外一种派系就是选择c系语言走游戏厂，或者硬件相关，或搞嵌入式。

薪资来说分化严重，在这里以本科传统 java / go 来说粗略的分几档吧。

>卷互联网中大厂年包基本稳拿35w ~ 70w+，主播转正保底的年包就落在了平均值以上；
>
>选择传统制造业的年包也稳定能拿20w ~ 45w；
>
>走央国企一般就是12w ~ 35w。
>
>哪怕完全不懂就业完全混了四年，只要最后努力找工作了往往也能靠学历有小厂兜底，薪资不好说，可统计样本很少，但私企在一二线城市月薪过w至少还是能保证的。
>
>！这里重点要注意的是工作强度，强度从10-6-5到9-11-6不等，建议优先注重一下时薪。
>
>互联网钱多溢价高，工作强度也不低。央国企虽然没钱，但胜在(相对)轻松稳定，近些年就业形势不断下滑的过程中含金量越发上升，更不用说非一线能开30w+还能965的这类头部非市场化央企了。
>
>(但这种顶级的一般都要双9起步，双华五起步，保研起手，泥吉并不是一个占优的变量)。

### 1.4 多线并行的幻觉

一类小东西的想法：开局卷绩点卷成绩肯定没什么错，能保研就保研，保不上就考研；考研不行再找工作，家里有条件的还能看看留学。

但往往等你真正走到大三，会发现这几条路争抢的是同一段时间，而且每一条都要求你在最关键的阶段投入近乎全部精力，对于95%的人来说，我们只能allin其中一条。

1. 对于保研和就业，基本无法并行，在大三下到暑期会发生非常严重的冲突。保研边缘人需要继续守绩点、打竞赛、做科研、准备夏令营和预推免；就业则需要做项目、刷算法、写简历、投日常实习和暑期实习。

存在极少数同时做成的神人，但对于大多数普通学生来说时间和精力只够一条路，保研人最危险的情况是为了等待一个不确定的保研结果，把就业准备也一并拖死。

2. 关于考研和就业，冲突则更加直接。考研需要长期、稳定且近乎封闭的投入，而互联网就业的关键准备和实习窗口同样集中在大三下到大四上。

等十二月考完以后再转就业，秋招主战场基本已经结束，迎面而来的就是补录和春招，以及无数同时转向就业的考研失败选手。所以考研前一定要提前接受付出的机会成本。

对于刚上大学的小东西，合理的一类风险对冲是**确立一条主线，再保留一条维护成本足够低的退路**。

保研为主，可以提前了解就业形式、至少把这篇readme看完，卷绩点可以先不实习，选择多积攒校内经历保央国企。

留学为主，可以同步优先实习，因为这既能帮助申请，也能极大程度支撑回国后就业；

就业为主，可以同时投互联网、制造业和国央企，简历项目和面试经验都能部分复用。关于一些升学或留学形式。

千万千万不要用完全allin保研的方式拖到大三下，用考研的方式拖到大四，最后想拿就业兜底，这时候就已经没了，泥吉这垃圾保研率每年中招的人数不胜数。

### 2.1 就业目标
本科企业就业方向也是非常非常多的，卷互联网大厂，走央国企，冲量化金融，走制造业，卷硬件，去AI新兴龙头等等等等。

我们要做的是根据想去的岗位，抓住最主要的内容，没必要的内容就无需过多涉及。但往往根据分类我们有一个非常粗略的重要程度排行：

**互联网类私企（eg 腾讯字节京东美团滴滴...）：**

> **学历 ＞ 实习 ＞ 项目 ＞≈ 竞赛 ≈ 开源经历**

过了学历门槛以后，**高质量实习基本是最硬的筹码**。竞赛，开源项目，项目更多承担证明技术能力的作用。

这里需要特别注意的是，在学校众所周知大家都在卷的**绩点，奖学金，四六级**等等，对于卷互联网几乎聊胜于无，没人在意。当然你可以写上来，来证明你是个好学生，只不过这种证明远远不如多掌握一门新的技术栈更有含金量。

**央电科类国企（eg 国家电网三大运营商银行科技岗一汽航天军工...）：**

> **学历 ＞ 专业匹配 ≈ 成绩排名 ≈ 绩点排名 ＞ 实习 ≈ 奖项竞赛 ＞ 学生工作 / 党员 / 证书 ＞ 项目 / 开源经历**

央国企更偏爱学生特有的清澈服从性，技术是次要的，更喜欢看重一套比较老实听话标准学生的东西：**985 / 211、硕士、专业对口、成绩不错、奖学金、四六级、学生干部、党员、竞赛荣誉**这些东西都会更值钱。项目和 GitHub 开源在这里通常没有互联网那么强的加成。**但是大厂实习依旧是抛开这些的课外最大加分项。**

同一件事情，在不同路线里的价值可以从 100 分直接掉到 0.5 分。

所以求一些小东西别闲的没事乱卷了，大学不清晰自己的目标，盲目乱卷无意义的事情，那确实还不如你天天打游戏摆烂的室友，至少人家目标是玩爽最终确实玩爽了。

这里有一个推论：

**如果你只想搞钱，互联网所谓的绩点评奖评优都几乎不重要，优先把所有精力放在技术提升和实习经历上，大家都知道学校里面的知识脱离时代什么用也没有。**

**如果你想稳定的去找个央国企，那就扮演好一个乖乖学习拿国奖卷绩点的好学生形象，实习是加分项不是必须项，非科班转专业是刚需。**

### 2.2 行业、岗位与技术方向选择

先说结论：**不要上来先问学 Java 还是 Go，先去看你想投的岗位到底在招什么人。** 语言只是工具，岗位、行业和市场需求才是你真正在选的东西。

本科生最常见的无非是后端、前端、客户端、测开、运维、嵌入式和算法这几大类。

后端岗位多、资料多、路线成熟，同样人也最多，面临的是最本质的计算机就业环境；

前端入门快，容易但2026的当下已经基本转向全栈岗位了；

客户端、音视频、游戏和嵌入式更吃 C/C++ 和底层基础；

算法和深度 AI 相关岗位上限高，但学历、论文、数学和竞赛门槛也不是普通开发可以类比的。

这两年又多了一大堆 AI 应用、Agent 和工程化岗位，看起来什么都能沾点边。但你仔细翻 JD 就会发现，企业要的还是能把模型接进真实系统、能解决稳定性和成本问题的工程师。

所以选方向最简单粗暴的方法，就是打开招聘软件和各厂官网，把你能接受的城市、行业和薪资筛完，真正统计一下有多少岗位、都在要求什么。选一个岗位数量足够、你不讨厌、六个月内又能做出东西的方向，然后去学它最主流的技术栈。别天天在网上参与语言圣战，你是来找工作的，不是来给编程语言当粉头的。

### 2.3 实习
无论走那种路线，企业实习经历都是极大加分点。之后的简历上有实习内容，也会作为第一重点优先关注你实习做的事情。所以对于就业来说就是**提升技术水平，多花精力卷实习经历。**

但是这里需要格外注意时间节点，卷实习，就注定了要对学校内的绝大多数事物断舍离，还需要和课程老师和导员斗智斗勇，这点在现在吉大是极为稀缺的，吉大早早醒悟出来实习的也是少数人。

**但学校和老师是真的困在科研和校园的象牙塔里半辈子，完全不懂就业现状，也不会在意你的未来发展和前途。更期望你和他们一样，成为一个老老实实上一辈子过时课程的乖学生，就像他们的来时路一样。**

### 2.5 竞赛与开源经历
首先，这两者对于 **绝大多数普通人** 只能算是边缘加分项，不会起一个主要的作用。因为这两者都极吃天赋和兴趣，绝大部分人其实并没有这些能力，所以往往到最后只能作为一个参与过烘托过的作用。

### 2.7 算法
现在这个时间节点写这个其实有点微妙。AI时代算法正在呈现一种考察趋势极速下降的地步，但近两年肯定还是不会绝种的，该刷还是得刷。

然后关于算法考察本身，其实是较为特殊的一环。其本质是因为候选人实在太多，不得不推出的一类固定筛选性环节，面试官只能用这种绣花拳脚的方式来间接低成本判断面试者的基本功。

工作中算法是完全用不上的，但是面试必须要有（大厂有手撕环节，小厂一般没有）。

#### 对于笔试（日常实习一般无，暑期实习和秋招一般有）：
这是目前AI时代变化试水最大的部分。

极端一点的比如阿里，蚂蚁直接取消了传统算法环节，转向选择知识点考察和AI Coding考察。

一般的比如百度，美团等把传统古法算法考察的分数降低到了20% ~ 50%。

传统的比如拼多多则一贯保持着古法全算法考察作风，但这已经是极少数了。

所以现在来说，笔试越发呈现走个过场的趋势，压根不看笔试成绩，仍然是主要看你简历来决定约不约面。而笔试中的第一题基本就是签到题，就是很简单，来了就能做出来。所以笔试对于80%以上的大厂就是走个过场。

#### 对于面试：
大部分情况，我们算法只需要刷力扣平台上的“hot100”即可，然后再逐层向外扩宽扩深，去覆盖考察的小部分领域。综上，算法没必要刷太多，面试大部分属于提前告诉你题库，笔试又不看成绩，且在当下考察越发呈下降趋势。
> [`https://leetcode.cn/studyplan/`](https://leetcode.cn/studyplan/)

建议尽早去刷，不是说一下你要刷几十几百道，那太痛苦了，但一定要养成刷算法的习惯，每天一道两道，或者复习，这在2026哪怕考察趋势极速下降的当下也是极为有用的。

### 3.1 就业标准时间节点

如果你大一上，又看到了这个帖子，跟着优雅0v0的路线走是绝对没问题的，还真的能落实下去，就最后等着开80w大包吧😡。

当然，大部分人是没有你优雅哥这个高瞻远瞩和执行能力的，对于吉大这个烂就业环境来说，知道秋招不在秋天，暑期不在夏天，能按时在大三下参加报名暑期实习，就已经算高瞻远瞩了。倘若暑期前还能再刷一段，在泥吉算的上就业领域大神。

所以我们必须以普通人的视角，阐述一段实现难度不高的就业标准时间节点：

1. 大三下/研二下开始 **暑期实习**：三月初黄金期，延续到六月末基本结束。各大企业投放包含转正的实习机会。

2. 大三暑假/大四上 **秋招**： 八月初到十二月————秋招补录。

3. 大四寒假/大四下 **春招**：二月底到六月，基本为秋招和考研失败者做最后兜底，捡漏为主，难度极大，是统一校招的最后机会。

关于距离重要节点的剩余时间，我们去做最有意义的事情。

关于什么时候开始投递找实习，这里有一个非常重要的信息差：

**不要等准备好了再投**。准备得怎么样只是找实习其中极小一个变量。市场现在有多少 HC、竞争的人有多少、现在处于什么招聘周期，同样是变量，而且这类变量的影响权重往往比你今天多学俩小时带来的变化大得多。结论就是无论当下准备现状如何，写好简历直接投，边投边学，就是当下进程中反直觉的最优解，找实习本身更是越莽越有，胜利永远属于勇敢者。
	
**对于八九月还是寒假投，因为暑期的实习生基本已经9成离职备战秋招，放出海量需填补的hc，8成的人又被学校课程卡着想着寒假再投，天然的找实习黄金期，相比你个人一天两天的进步，真的追不上市场供需变化带来的差距。**

实习从0开始准备到开始投递，无论你是面向面试学习，还是古法知识点流派学习，我个人的小建议是不要超过3个月，越早投递越好，找实习一定是 **运气 ＞ 时间窗口 ＞ 实力** 的，到后面越拖越难找。

一段实习在简历上的时间就是三个月以上为标准，当然，3月末进，5月初离职，这在简历上也是三个月啊，灵活变通一点，合理优化和包装，懂我意思吗。

### 3.2 校招完整流程与常见术语

一些互联网黑话的前情提要：

- **JD**：岗位描述，你要做什么、需要什么能力，投递前请真的读一遍。
- **HC**：招聘名额。面试过了不代表一定有 HC，组里人很喜欢你也不代表审批一定能下来。
- **提前批 / 正式批 / 补录**：正式秋招前提前抢人、秋招主批次，以及后期有人拒绝或者仍有缺口时的捡漏批次。
- **泡池子**：面试基本过了，但公司还在把同批候选人放在一起排序，不是稳了，也不是挂了。
- **OC**：Offer Call，一般是电话通知录用意向或者询问你的接受意愿。
- **意向书**：比口头通知更正式，但仍然需要看具体文件，别看到“意向”两个字就开始庆祝入职。
- **白菜 / SP / SSP**：招聘里常见的录用评级黑话，一般影响薪资和谈薪空间，但公司内部标准各不相同。
- **两方 / 三方**：两方是你和公司之间的约定，三方是学生、公司和学校之间的就业协议。它们和正式劳动合同不是同一个东西。

一个常见的校招流程大概是：

> **投递 → 简历筛选 → 笔试 / 测评 → 多轮技术面 → HR 面 → 池子 / 审批 → OC / 意向 → 谈薪 → 正式 Offer → 签约**

当然，不同公司会跳过其中某些环节，也有的公司会让你面五六轮。一般日常就是两技术面（字节等等少数三面技术面），暑期和秋招基本都是三技术面。

### 3.3 简历与求职材料准备
第一段实习来说，简历往往需要两个能打的项目，一个可以看懂的编程语言，一系列技术栈的八股问题。当然对于大厂还有隐性的算法问题，要能刷出hot100的大部分原题。

对于简历的实质性准备，要注意的点太多了。

#### **简历内容性价比**
有实习问实习，没实习问项目，项目太烂大街，或者实在不匹配，就只能问八股拷打技术栈广度深度去看你有没有自己的思考。

所以我们第一段实习的最大方向就是项目和八股。。特殊内容：竞赛，开源经历，个人技术博客，有含金量的可以写一写，属于边缘加分项，极优秀的可以另开辟一条道路去求职了，但脱离混子求职掌握的范畴了。

学校奖学金，绩点排名，英语水平，校级比赛.....这一类完全无人在意，属于实在没招了，你可以去写一写，可以用于混简历。

个人性格，学习课程，学校实验大作业。非要写这种东西上去，面试官基本都会觉得你连一页简历都凑不齐，实在拿不出任何例证了，基本都是减分项。

#### **简历撰写**
善用AI包装，但是不要只用AI。很多东西用ai包装在你的简历上实际上是没有信息量的，要想清楚面试官想看见什么，一切要站在通过简历筛选通过面试考察的角度上。这里就不详细讲了。前面两个视频里可以阐述的很清楚。也可以加我让我看看简历。

没有说一个固定风格的万能解法。简历撰写本身可以说是一门艺术，基本能奠定你30%的最终结果。请慎重再慎重编写每一个字，都有可能牵引面试环节去多走一步。

有空我会出个视频，现在太懒了天天玩。

除了简历本身，真开始校招前还建议把这些东西一次性准备好：**PDF 简历、成绩单、四六级证书、获奖证明、证件照、实习证明，以及能展示的 GitHub、博客或项目 Demo。** 有英文或国际化岗位需求的，再单独准备一份英文简历。

简历最好根据岗位准备不同版本，让最匹配 JD 的经历放在最前面。网申上传后记得检查自动解析，学校、年份和实习时间解析错了还不改，那确实是连挂都挂得很冤。

最后把邮箱垃圾箱、手机骚扰拦截和静音模式检查一遍。招聘季很多电话你打回去根本打不通，也别指望 HR 一定会第二次找你，错过重要约面才真的会让人红温。

### 3.4 信息渠道与内推

主要获取信息渠道有：
**牛客，小红书，offershow，脉脉，Boss直聘，实习僧等**

Boss 和 实习僧 算头部适合找日常实习的平台了，可以直接联系招聘方。

牛客适合找面经和笔试信息，校招时间线，以及一些有用的就业信息差。

小红书有时面经和经验贴会比牛客还多，也有一些便宜优质的文件。

但两者也是贩卖焦虑重灾区，注意甄别。

内推码99%都是0作用，不要想着别人主动送你的会有什么好东西，大部分时候只是让学长有机会拿奖金；能把简历直接送到具体团队和招人 Leader 手里的组内直推，才可能真正加快筛选。

### 3.6 笔试、性格测评与 AI Coding

现在的线上测评大概可以分成四块：**行测、性格测评、技术客观题，以及代码题。**行测常见的就是言语理解、数字计算、图形推理和情景判断，不会也不用怀疑人生，找几套熟悉题型和时间节奏就行。

性格测评最怕的不是你不够完美，而是同一个问题换个说法你就前后矛盾。没必要把自己塑造成一个永远加班、永远快乐、永远服从的超级牛马，但也别在里面刻意选一堆极端答案。保持一致、正常做人，已经能解决大部分问题。

技术笔试有的是选择题加传统算法，有的是 ACM 输入输出，有的只要填核心函数。这两年也开始出现 AI Coding、代码补全、Debug 和阅读陌生代码的混合题。考前一定看清平台规则，能不能用 IDE、能不能切屏、有没有摄像头监控，别先被考试平台弄死了。

最后，不建议找人代做，也别觉得有 AI 就可以闭眼复制，一旦被认定是诚信问题，比单纯不会严重得多。菜就多练，这个确实没有什么魔法。

### 3.7 面试完整流程与面试官类型

实习的话一般大厂是两轮技术，部分厂有HR面。小厂实习可能就一轮技术就是了。秋招的话一般是三轮技术面+HR面。

每次面完快的话可能十分钟就有结果，慢的话可能三四天，四五天，甚至一周。和视频讲述一致，一定不要急，面试就是随堂小测。

不同轮次的面试官在意的东西并不一样。一面很多是组内工程师，看你基础过不过关、项目是不是真的、以后能不能一起干活；二面往往更接近直属 Leader，会更关注你解决问题的深度和岗位匹配；再往后的主管或者总监面，才会更关注业务理解、稳定性和整体潜力。

所以多出一轮面试不一定是坏事，可能是团队还想继续确认，可能是同水平候选人需要再排一次，也可能只是内部流程有变化。别看见别人三轮你四轮，就开始在宿舍里研究什么秋招玄学。

### 3.8 面试前准备与自我介绍

关于面试前的准备，我觉得还是比较多的，首先你要有一个可以倒背如流且2分钟突出所有优势的自我介绍（对于国际化相关部门，一定记得准备被一份英语自我介绍）。

然后可以提前在牛客小红书搜一搜相关的面经。完全不指望出原题，因为哪怕同一个公司同一个部门也可能上百人，很难说遇到同一个面试官，但是往往你可以看出一家公司拷打的宏观风格是怎么样的，再做针对性的准备。

例如百度很有老派的计算机基础和老派拷打八股算法的风格，字节就是爱拷打408爱刁钻项目细节的mean风格。

一个好用的自我介绍不用整成演讲比赛，但至少要说清楚：你是谁、在哪读书、最能打的实习或项目是什么、取得了什么结果，以及你和这个 JD 为什么匹配。技术面多讲能力和项目，HR 面就别上来背半天底层原理，没人想听。

线上面试前把摄像头、麦克风、耳机、网络和备用热点试一遍，屏幕共享时别让奇怪聊天窗口满天飞。简历、JD、自我介绍和项目架构图可以放在手边，但别眼睛一直往旁边飘。

<br>

### 3.9 简历深挖、项目拷打与系统设计

尽量对于简历上每一个字都要有应对再写上去，不写不扣分，写上但是基础问题没答对那就是极大减分。

项目拷打根本不是让你再给面试官念一遍简历。面试官真正想看的是：你知不知道这个项目在解决什么问题，你自己到底做了什么，为什么选 A 不选 B，遇到过什么故障和性能瓶颈，以及你说的优化到底怎么证明有效。

每一个写上简历的项目，至少要能经得起这些问题：

- 架构和核心数据流是什么？
- 你负责了哪一部分，团队怎么分工？
- 为什么使用这个组件，替代方案有什么？
- 最难的问题、线上故障和最糟糕的决策分别是什么？
- QPS、延迟、数据量和资源消耗大概是多少？不知道就直说不知道，别闭眼编个亿级并发。
- 怎么做幂等、一致性、限流、降级、重试、监控和告警？
- 流量扩大十倍会先死在哪里，现在重做一次会怎么改？

系统设计也不是上来就开始默写八股架构图。先问清需求、数据量、读写比、延迟和一致性要求，再画高层架构和核心数据流，接着找最可能的瓶颈，最后讨论容灾、扩展、监控、成本和方案局限。

设计题没有唯一标准答案，面试官看的是你怎么权衡，不是你能不能把 Redis、Kafka 和分布式锁全部塞进一张图里。

<br>

### 3.10 HR 面试与行为问题

都走到 HR 面了再翻车确实很可惜，但 HR 面也绝不是走个过场。技术面看你能不能干活，HR 面更关心的是你会不会来、能干多久、薪资和地点能不能谈拢，以及有没有什么明显风险。

常见问题无非是：为什么不考研、为什么本科就业、为什么选这家公司和这个城市、手里还有哪些流程和 Offer、期望薪资、能不能接受调岗、什么时候能到岗，以及优缺点、失败经历、团队冲突、抗压和职业规划。

这些问题要提前想，但不要编造一个一追问就穿帮的虚假人生。最稳的回答方式是从真实经历里选取对岗位有利的部分，再把逻辑讲清楚。例如缺点不要回答“我过于追求完美”这种老掉牙的反向夸奖，而是说一个真实但可以改善的问题，它造成过什么影响，你又在怎么改。

问到手上其他机会时，如实说自己能公开的进度，同时表明你对这家公司的兴趣和原因就行。没必要装成一个手握十个大厂 Offer 的秋招皇帝，更别为了表忠心就当场承诺自己永远不会走。

<br>

### 3.11 反问环节与团队判断

反问不是给你表演“我对贵司非常感兴趣”的固定节目，而是你在整个面试中为数不多的反向尽调机会。公司在选你，你也得判断这个组到底能不能去。

问普通工程师，可以问技术栈、日常开发流程、Code Review、新人一般做什么，以及实习生能不能碰到真实业务；问 Leader，可以问这个岗位为什么招人、是新 HC 还是替换、考核和转正怎么看、未来半年最重要的业务是什么；问总监，可以问这块业务在公司内部的位置、是增长还是收缩、和竞争对手相比的优势。

到 HR 环节，再问薪资构成、工作地点、培训、调岗、审批和签约时间。薪资不建议在技术一面就追着工程师问，他大榇率根本不知道你能开多少；也别问官网一搜就有的公司规模，或者对一个普通工程师问“公司未来十年的战略规划”，确实有点难为人家了。

如果你不知道问什么，最实用的一个问题是：**如果我有机会加入，从现在到入职之前，您建议我优先补齐哪部分能力？**既能拿到真正有用的信息，也能从侧面判断对方到底想不想要你。

<br>

### 3.12 不会的问题怎么答与面试复盘

面试里遇到不会的问题是必然的，没人能把计算机这片学海全部背完。

完全没听过就说自己对这部分不熟悉；有一点理解但不确定，就先说“我不能确定，但我的理解是”，再把推理过程讲出来。算法题先给能跑的暴力方案，再讨论怎么优化；题意有歧义就先问，别自己对着错的需求写半天。

不会一道题不一定直接寄，但偷偷切窗口搜答案被发现，基本就会从能力问题升级成诚信问题。需要思考就直接说“让我想一下”，低头在纸上画两笔没什么丢人的。面试官给提示就接住，发现自己说错就改，别为了证明自己很有个性当场开辩论赛。

然后是复盘。**没有复盘的面试，基本等于白面。**面完以后趁记忆还没消失，立刻记下公司、岗位、团队、轮次、时长、全部问题、哪些答得好、哪些答得烂、算法有没有写完，以及反问得到了什么信息。

对于不会的问题，不要只是复制一份网上答案就完事，而是放回自己的八股和项目知识体系里。当你面到第十家时，前九家的问题就是最贴近市场的个人题库，这比漫无目的再背五百页八股有用得多。

### 3.13 第一份实习

正打算出个视频讲一讲呢，本来说9月就讲讲吧，太懒了现在也没动笔，但是会出的，慢慢来。

第一份实习的核心目标只有一个：**完成从“只有项目的学生”到“做过真实业务的候选人”的第一次跳跃。**所以零实习时别光盯着公司名字，更应该问清楚有没有导师、能不能接触真实代码库、做的是不是上线业务，以及团队愿不愿意让你学东西。

当然能去中大厂最好，实在进不去也不用死等。一家业务真实、代码正常、团队靠谱的中小公司，至少能让你拿到下一家的入场券。但那种几个人、业务说不清、上来就让实习生一个人手搓整个系统，还想用“成长空间”给你抵工资的，该跑还是快跑。

找第一份实习时也不要虚构实习、冒领项目和乱编数据。你可以把自己真做过的东西讲得更清楚，但第一份实习就是为了解决“没有真实经历”这个问题，别还没进公司就先给自己埋一堆之后永远解释不清的雷。

### 3.14 第一份实习后继续刷

进公司以后最值钱的不是那张实习证明，而是第一次看清楚一套真正的工程到底怎么运转。代码库怎么分层，需求怎么评审，任务怎么拆，Code Review 在看什么，测试、灰度、发布、回滚、日志、监控和告警怎么串起来，这些才是学校玩具项目很难给你的东西。

多看代码、文档和技术方案，遇到线上问题就看老工程师怎么定位，开需求会和复盘会也别只顾着挂机。你不一定能亲手实现全部系统，但至少应该搞清楚自己所在的模块怎么和上下游交互、为什么这样设计、出问题以后怎么兜底。

同时开始为下一段经历准备。把真正完成的需求、解决的难题、效果数据和自己的贡献记录下来，然后在不泄露公司机密、用户数据和内部代码的前提下写进简历。公司的东西不是你的开源练习仓库，也别为了证明自己很牛把内部架构和数据往网上扔。

有了第一段以后，下一次投递才可以更有目的地挑公司、团队和业务。别因为终于有个地方要你就立刻开始讲忠诚，日常实习的转正和留用都是附加项，技术成长和下一张更好的入场券才是主线。

### 3.18 OC、意向、谈薪与正式 Offer

面试过了、HR 说很想要你、Leader 说组里有 HC，这些都不等于你已经拿到 Offer。OC 和意向是非常积极的信号，但后面仍然可能有排序、HC 和审批环节。所以没有收到正式书面文件以前，手里其他流程不要随便停。

谈薪时先问清楚对方说的“总包”究竟由什么组成：月薪、一年几薪、年终奖的确定性、签字费、股票、补贴和试用期折扣分别是什么。一个写着 50w 的总包，里面如果有十几万是不确定奖金和分期股票，和稳定到手的 50w 根本不是一回事。

真觉得价格低了可以谈，尤其是手里有其他真实 Offer 的时候，这本来就是正常的双向选择。但谈薪不是漫天要价，也不是编一个不存在的大包去赌 HR 不会验证。把自己的面试表现、市场行情、其他选择和接受底线想清楚，有理有据地提出来就行。

正式 Offer 下来后也别只看那个最大的数字，把公司主体、岗位、工作城市、薪资结构、试用期、报到日期、答复截止日期和附加条件全部看完。电话里说过但文件里没写的重要信息，最好通过邮件或者其他书面方式再确认一遍。

### 3.20 两方、三方、签约与违约

这部分非常现实，也非常容易因为“大家都这么说”就稀里糊涂签了。两方、三方、Offer 和正式劳动合同不是同一个东西，法律性质、生效条件和违约后果也不一样。签之前不要只看薪资，还要看违约金、解约条件、报到时间、工作地点、岗位调整条款和解约函办理时间。

真要解约时，通常不只是给钱这么简单，还可能涉及公司出具解约材料、学校就业系统审核、重新领取协议和新公司的等待时间。

所以签保底当然可以，但你得提前知道这张保底到底有多大的退出成本。

具体流程和规则每年、每个学院、每家公司都可能变。**真到签约和违约阶段，一定以当年吉大就业部门、学院和公司给出的书面说明为准。** 网上学长三年前的经验可以帮你知道该问什么，但不能替你承担今年签下去的后果。

### 3.21 秋招补录与春招

秋招补录一般来自有人拒 Offer、部门临时新增 HC 或者前面的人没招满，岗位少、窗口短，但有时候确实可以捡到前面不敢想的机会。这个阶段要做的就是继续看官网和招聘群，保持能随时面试，别因为主战场结束了就直接把所有准备全删了。

春招则更像秋招剩余名额和新需求的第二轮重新分配。公司和岗位数量往往比秋招少，同时还要和考研、考公失败以及回国求职的人一起抢。它可以是补救机会，但绝对不应该成为“我秋招先不急，反正还有春招”的借口。

如果真的到了春招，先复盘秋招到底卡在哪里：没有约面就改简历和投递方向，有面试没通过就追着面试记录补洞，都到谈薪还没结果就检查定位和选择标准。春招时间更短，没时间让你再从头漫无目的学三个月，必须找到那个真正卡死你的变量直接解决。

找实习和秋招的投递时间。很多人特别喜欢等，永远在等准备好了再投。但问题是准备得怎么样只是其中极小一个变量。市场现在有多少 HC、竞争的人有多少、现在处于什么招聘周期，同样是变量，而且这类变量的影响权重往往比你今天多学俩小时带来的变化大得多。

### 4.7 只看公司title，不看岗位和团队

校招时最容易被骗的就是那个又大又亮的公司名字。好像只要进了某个大厂，无论做什么都能自动升级。但你真正每天面对的是具体团队、具体 Leader 和具体业务，不是大楼门口那块 logo。

同一家公司里可以同时存在核心增长业务和没人管的边缘维护组，也可以有愿意带人的好老板和把实习生当便宜人力的神人。选的时候至少问清楚岗位是新增还是补人、业务是增长还是收缩、新人能做什么，以及这个 Leader 值不值得跟。

当然，大公司的工程规范、复杂度和下一份工作的简历认可度通常更好，但这只是一个重要变量，不是唯一变量。一个你完全不喜欢、学不到东西、业务随时可能没了的大厂岗位，不会因为发朋友圈好看就突然变成神仙工作。

### 4.8 拿到一个 Offer 就停止搜索

第一个 Offer 的意义非常大，它能给你保底，也能让你之后的面试终于不再患得患失。但它的意义是让你更放松地继续往上面，不是让你当场关闭官网、删掉题库，从此开始庆祝秋招结束。

只有一个选择的时候，你根本不是在选，而是在接受。薪资没空间谈，团队再奇怪也不敢拒，对方一个签约截止日期就能把你拿捏得死死的。所以在书面 Offer 和签约条件真正稳定之前，手里其他流程该推还是推，能多拿一颗麦穗就别只抱着第一颗开始感动。

当然，这不是让你无限面下去玩集邮。当某个 Offer 已经在薪资、团队、城市和风险上都明显超过后续机会，就可以停止给自己制造新的焦虑。最怕的不是适时停止，而是还没有比较就被第一个结果绑架。

### 4.9 别人的路线直接复制

网上的所有速通路线，包括这篇 README，都只能告诉你作者在当时的背景、时间点和运气下是怎么走的。别人用 Java 后端三个月拿到实习，不等于你现在照着他的课程顺序一节不落地看，第九十天就会自动掉下一个 Offer。

入学年级、学院管理、现有基础、家庭条件、目标城市和当年市场都会改变最优路线。有人大一就能打 ACM，有人大三下才第一次听说暑期实习，两个人硬走同一条路只会有一个人受罪。

真正应该复制的是别人做决策的方法：他怎么确定目标，怎么查市场，怎么在时间不够时做取舍，怎么通过投递和面试反向修正路线。折腾半天最后得出的结论如果只是“某某学长说要刷 Hot100”，那确实还是没有长出自己的脑子。

<br>

---

### 4.10 简历包装不等于简历造假

简历当然要包装。把一句流水账改成有背景、有行动、有结果的表达，把最匹配岗位的内容放在最前，删掉一堆没人在意的课程和自我评价，这都是正常优化。但把没做过的实习、项目、职责和数据写上去，就不是优化，是造假。

最容易翻车的就是把团队做的东西全部写成自己独立设计，把未经验证的优化编成几百倍性能提升，或者为了好看就把实习时间和公司信息整个换了。面试官可能不会给每个实习生做全面背调，但他只要追问几轮架构、指标、故障和你的具体贡献，真假很快就能看出来。

最简单的边界就是：**简历上的每一句话，你都能说清证据、过程和自己的责任边界。**不能对外说的东西就做匿名和抽象，不知道的数据就不编，团队的能力就别全部贪到自己身上。这不仅是诚信问题，也是保护你自己在面试时不被一串谎言拖死。

<br>

---

### 4.11 把一次面试失败当成能力判决

面试结果受的随机因素太多了：部门当天还有没有 HC，面试官爱问什么，前面有没有一个比你更匹配的人，甚至你们两个当天状态好不好，都会影响结果。一次面试只是一个小样本，不是上天对你计算机生涯的终审判决。

如果你只投四家，挂一家就等于秋招少了四分之一，当然会觉得天塌了。但当你的投递和面试数量足够多，一家的失败就只是一条新的复盘记录。海投的意义不只是多拿结果，也是把单次随机性对你心态的影响降下来。

但也别反过来把所有失败都怪给运气和面试官。如果连续五家都在项目深挖上爆炸，那就是项目真的没吃透；如果每次都是算法写不出来，那就回去刷题。一次失败不说明你不行，重复出现的失败模式才是市场在明确告诉你问题在哪。

<br>

---

### 4.12 只看年包，不看时薪、城市和隐性成本

年包是最好截图发群的数字，也是最容易把人骗昏的数字。一家公司多给你几万块，但每周多上一天班、每天多干三个小时，换算成时薪可能还更低。更不用说一线城市的房租、通勤、落户和离家成本，这些都不会因为你的 Offer 很好看就消失。

薪资结构也要拆。固定月薪是多少，年终奖是保证还是看绩效，股票几年归属，签字费是不是要求服务期，补贴有没有期限。别人口中的年包算法和你的算法可能根本不是同一个东西。

最后还要算风险。一个价格极高但业务收缩、试用期刷人、团队疯狂流动的岗位，和一个总包稍低但学得到东西、生活也能接受的岗位，不能只用前者多出的几万块一键定胜负。工作是真的要去做的，不是只用来在 OfferShow 上留一行数字。

<br>

---

### 4.13 把流程推进、口头承诺和意向书当成正式 Offer

校招里最危险的错觉之一，就是“Leader 都说很想要我了，应该稳了吧”。口头承诺可能是真心的，但 Leader 控制不了公司的 HC、排序和审批。往年转正率很高，也不代表今年名额不会突然砍到只剩一半。

同理，OC、意向书、体检通知和谈薪都是非常好的信号，但只要正式文件还没下来，就不要把所有其他机会一键清空。就算书面 Offer 已经下来，也要把录用主体、岗位、城市、薪资、报到和签约条款看完，而不是只看邮件标题有个“恭喜”就开始退群。

你没必要带着恶意怀疑每个 HR 和 Leader，但必须知道个人好意和公司承诺是两回事。一切重要信息尽量落到书面，一切未完成的流程都保留退路。这不是不讲信任，是求职者对自己前途最基本的风险管理。

<br>

### 4.14 不懂装懂，和面试官硬争对错

自信和嘴硬是两回事。自信是你能把自己会的东西讲清楚，不会的地方也能正常分析；嘴硬是明明没学过还开始现场编，被面试官指出来以后又为了面子开始和人家对线。

面试官当然不一定永远正确，遇到自己确定的问题可以补充前提、说明依据，甚至礼貌地指出不同结论。但你的目标是让对方看到你的推理能力和沟通方式，不是必须在二十分钟内分出一个谁才是计算机正统。

如果对方的指正是对的，就承认、修正并继续；如果对方的说法确实有问题，你可以表达自己的理解，但没必要把气氛弄成毕设答辩对骂。面完觉得对方抽象，最多复盘记一笔然后不去这家公司，没必要当场为了一口气丢掉整个流程。
