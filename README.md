### 1.1 常规路线与吉大现状：
在讨论到底该保研、考研、留学、考公还是直接就业以前，我们先把吉大的真实情况摆在桌面上。

#### 国内升学

首先是**国内升学**，泥吉是绝对的考研大校，或者可以称之为向上冲刺的升学跳板。

提到考研前我们必须要说保研，保研率对于cs类工科来说，只能用幽默评价，甚至打不过很多的京区211。26年也出现大面积保研比例下滑的趋势，某学院比例纯硕士一下从15.6%到13.2%，卡在这2%的学生名单一公布直接没招了，要么百日极限冲刺考研，要么无实习俯冲就业。

在这种烂完的情况，叠加泥吉的就业氛围很差的前提，造就了泥吉如今所谓**考研氛围浓**的最终体现。学校整体学习氛围不差，但就业氛围相对弱很多，尤其低年级阶段，大多数人并没有很强的自学、项目和实习意识，最自然的路径就是跟着培养方案上课考试卷绩点。等到了大三保研无望以后，考研就成了阻力最小、信息最多、身边人也最多的一条路。

#### 出国留学认可度

然后是**出国留学认可度**，这方面吉大的认可度其实相当不错。

仅去看 2024 届本科生数据，共有 556 人境外留学，其中 445 人进入 QS 前 100 高校，占 80.04%；去向包括新国立、南洋理工、港大、港中文、帝国理工等等。当然，留学本身是另一套游戏，资金成本、地区选择、回国认可度都要单独算账，但这里所表达的是泥吉的门槛和分数策略是很可以的，这里我们后面再展开。

#### 就业认可度

最后是**就业认可度**，首先小东西真没必要天天刷什么次9末9争霸赛，镇闹得麻麻的，真找个班上就会发现哪里来的那么多规矩，都是985，985之间差距很低，一个门槛而已，泥吉就是及格表现的一个985。

基本上98%的情况不会卡吉大，更不会有什么山川吉里山川在前能进去，但是泥吉进不去的情况。但可能这里小东西会问了，啊呀那不是还有2%嘛，这里点名阿里卡23所目标院校，以及类似极少数头部量化的情况，这种确实没有办法，但基本不影响常规就业。对于**大部分互联网、国央企、银行、研究所、普通科技公司**来说，学历这一关基本都够用。甚至对于一些老登来说，他会潜意识把吉大归类为印象中十多年前稳定前十如今稍逊的级别，吃一波历史红利。

#### 综合来看

泥吉性价比极高，这块牌子足够你继续往下玩，不会成为那个最先卡死你的变量。

然后很值得一提的是泥吉极优秀的校友人脉资源，吉人天下这一块真不是吹的，你可以在世界上的任何一个犄角旮旯发现怎么这也有曾经的学长学姐。

### 1.2 本科就业路线

由于我自己是选择了本科就业，言辞文笔肯定要更偏向本科就业一点。在现在快速迭代的AI时代前提下，我真心认为倘若早早醒悟，早早脱离学校的象牙塔，选择本科就业就逃出来，这是一个高性价比极高的选择。

注意，这里我说的是逃。因为哪怕你选择考研读研留学也远远不是终点，在2026秋招今天的现状下，9硕的就业人数就已经远远高于9本就业人数了，读一个研究生，凑一个双9在现在也没有什么稀缺性可言。大部分双9本硕出来依旧是跟本科生抢着干开发，能否拿到好工作还极大程度取决于导师放不放实习，比起本科的无忧无虑，读了研反而可能会受众多约束。

甚至在如今，已经被卷到有了一些大厂开发也必须要硕士门槛的趋势，因为现在的环境根本不缺人，在近些年就业形势不断下滑的过程，趁着本科能就业就逃出去就业工作三年相对性价比极高。

以吉大计算机本科就业薪资和就业去向来说，绝大部分都是选择传统 java / go 去企业搞后端开发，然后少数突击选择前端测开运维，另外一种派系就是选择c系语言走游戏厂，或者硬件相关，或搞嵌入式。

薪资来说分化严重，在这里以本科传统 java / go 来说粗略的分几档吧。卷互联网中大厂年包基本稳拿35w ~ 70w+，主播转正保底的年包就落在了平均值上；选择传统制造业的也稳定能拿20w ~ 45w；走央国企一般就是12w ~ 35w。然后哪怕完全不懂就业完全混了四年，只要努力找工作了往往也能靠学历有小厂兜底，薪资不好说，可统计样本很少，但私企在一二线城市月薪过w至少还是能保证的。这里重点要注意的是工作强度，强度从10-6-5到9-11-6不等，央国企没钱，但胜在轻松稳定，近些年就业形势不断下滑的过程中含金量越发上升。

### 2.1 先定义我们的目标
本科就业方向是非常非常多的，卷互联网大厂，走央国企，冲量化金融，走制造业，去AI新兴龙头等等等等。

我们要做的是根据想去的岗位，抓住最主要的内容，没必要的内容就无需过多涉及。但往往根据分类我们有一个非常粗略的重要程度排行：

**互联网类私企（eg 腾讯字节京东美团滴滴...）：**

> **学历 ＞ 实习 ＞ 项目 ≈ 开源经历 ≈ 竞赛**

过了学历门槛以后，**高质量实习基本是最硬的筹码**。竞赛，开源项目，项目更多承担证明技术能力的作用。

**央电科类国企（eg 国家电网三大运营商银行科技岗一汽航天军工...）：**

> **学历 ＞ 专业匹配 ≈ 成绩排名 ≈ 绩点排名 ＞ 实习 ≈ 奖项竞赛 ＞ 学生工作 / 党员 / 证书 ＞ 项目 / 开源经历**

央国企更偏爱学生特有的清澈服从性，技术是次要的，更喜欢看重一套比较老实听话标准学生的东西：**985 / 211、硕士、专业对口、成绩不错、奖学金、四六级、学生干部、党员、竞赛荣誉**这些东西都会更值钱。项目和 GitHub 开源在这里通常没有互联网那么强的加成，除非投的是明确的研发技术岗。

同一件事情，在不同路线里的价值可以从 100 分直接掉到 5 分。所以这里有一个推论，如果你只想搞钱，互联网所谓的绩点评奖评优都不重要，都知道学校里面的东西脱离时代什么用也没有。如果你想稳定找个央国企，那就扮演好一个乖乖学习拿国奖卷绩点的好学生形象。

### 2.2 实习
无论走那种路线，企业实习经历都是极大加分点。之后的简历上有实习内容，也会作为第一重点优先关注你实习做的事情。所以对于就业来说就是**提升技术水平，多花精力卷实习经历。**

但是需要注意时间节点，卷实习注定了要对学校内的绝大多数事物断舍离，还需要和课程老师和导员斗智斗勇，这点在现在吉大是极为稀缺的，吉大早早醒悟出来实习的也是少数人。但学校和老师是真的困在象牙塔半辈子，不会在意你的未来发展和前途，更期望你成为一个老老实实上一辈子课程的乖学生。后面会详细讲怎么找实习。

关于实习公司选择，日常实习优先去选title高业务好的互联网公司，难度更大，认可度更高，给的钱也不错。

暑期实习可以多考虑一下转正率，虽然转正是大饼我们也不能allin，但是没有转正秋招可能会很难受。我当时进来是因为说组里年年都是100%转正率，结果呢，最后出来 5 进 2。他妈的组里实习生全都傻了，同答辩的科软实习一年的最后也没给转正，同答辩的实习半年海硕也落败了，只能说暑期转正全都是饼，千万不能allin。但是你说不要转正了，全力allin秋招，没有保底又处处受限，一路去做一些找实习根本看都不看的小厂，我感觉也太难受了，综合取舍吧，只能说现在的就业环境手心手背都是屎。

### 2.3 绩点
刚才我们其实已经提到过了。卷学校内的学习，是为了走卷绩点保研或出国的路线，和就业路线是矛盾的。实际上互联网就业来说， 0 个人在意你的学校学习什么样，大家都知道学校内的课程对于计算机就业什么用都没有。

哪怕是所谓的数据结构计网操作系统，也是 0 作用，0 作用，0 作用。**千万不要对于学校课程抱有任何的幻想，早早脱离学生做题思维。** 跟着学校课程学这些去就业，对于就业性价比不亚于出国通勤方式选择蛙跳，正常哪怕古法啃代码去学技术栈不说是坐火车也算是坐轮船吧，时间长了人家至少能到目的地，跟着学校学这些破应试的东西蛙跳一半不累死都是神人了。

所以对于互联网就业来说，保证不挂科即可，我自己绩点不说倒数，70%以下是有的，但这基本对互联网就业是 0 影响，大学真真切切玩了两年半，拿个互联网开发大包我已经相当满足了。

那绩点就没用吗？当然有，绩点代表的是你的服从性和一定的学习能力，这点央国企往往看的特别重。但话又说回来了，真正好的央国企硕士应届是必要绝对条件，本科绩点好的都保研了，差的玩爽了或者就业去了，那没那么好的卡在中间怎么办呢？或许没什么办法了。几千块钱奖学金？几千金额本身远不如这个名头本身重要，也没互联网实习半个月工资高，感觉真是闹的麻麻的了。

当然了反正大家一般都是期末突击，能多考点就多考点，自己看着也开心，绩点高了当然不可能有坏处。

### 2.5 项目与八股
可是第一份实习我什么都没有，怎么办呢？ **这时候最重要的就是你的项目。** 

简单理解，项目就是能展示你技术能力和思考的实现产物。一个项目往往可以体现你对于一个问题方方面面的思考深度，大厂尤其喜欢问这些而非技术实现本身。比如问技术就是问你这个xxx是怎么实现的，问思考就是问你是怎么选择了这种技术选型而非另一种。**这里注意的是，学校的任何课设作业都是绝对的电子垃圾，当不了找工作的项目。**

大家找项目基本都是直接买，或者学习某黑马用烂大街的经典项目，再者就是在github翻一翻开源的好项目进行学习。AI时代，我是利用这个窗口直接vibe了一个出来，平时有想法的也可以参照我的思考，虽旁门左道但是能走通的： https://xhslink.cn/o/7aS88LEgOUt 。

然后就是八股，这类东西是最好速成的，基本上 0 基础也能靠理解记忆的方式在一个月内掌握大部分高频八股。说是八股，但是死记硬背基本和念代码学编程语言没什么区别了。八股终归只是一种调侃的说法，本质八股是一种面试考察中过于泛化的通用计算机问题的解决思想和方式，是要自己去理解清楚的，你要动动脑袋有自己的思考。在公司接触实践的老前辈们大多数不爱问这类问题，没东西想问，迫不得已下才会问八股，目的是去看我们对于基础的掌握能力，其次是有没有属于自己的思考。

### 2.6 算法
现在这个时间节点写这个其实有点微妙。AI时代算法正在呈现一种考察趋势极速下降的地步，但近两年肯定还是不会绝种的，该刷还是得刷。

然后关于算法考察本身，其实是较为特殊的一环。其本质是因为候选人实在太多，不得不推出的一类固定筛选性环节，面试官只能用这种绣花拳脚的方式来间接低成本判断面试者的基本功。工作中算法是完全用不上的，但是面试必须要有（大厂有手撕环节，小厂一般没有）。

#### 对于笔试（日常实习一般无，暑期实习和秋招一般有）：
这是目前AI时代变化试水最大的部分。极端一点的比如阿里，蚂蚁直接取消了传统算法环节，转向选择知识点考察和AI Coding考察。一般的比如百度，美团等把传统古法算法考察的分数降低到了20% ~ 50%。传统的比如拼多多则一贯保持着古法全算法考察作风，但这已经是极少数了。
所以现在来说，笔试越发呈现走个过场的趋势，压根不看笔试成绩，仍然是主要看你简历来决定约不约面。而笔试中的第一题基本就是签到题，就是很简单，来了就能做出来。所以笔试就是走个过场。

#### 对于面试：
大部分情况，我们算法只需要刷力扣平台上的“hot100”即可，然后再逐层向外扩宽扩深，去覆盖考察的小部分领域。综上，算法没必要刷太多，面试大部分属于提前告诉你题库，笔试又不看成绩，且在当下考察越发呈下降趋势。

### 3.1 就业标准时间节点

如果你大一上，又看到了这个帖子，跟着优雅0v0的路线走是绝对没问题的，还真的能落实下去，就最后等着开80w大包吧😡。

当然，大部分人是没有你优雅哥这个高瞻远瞩和执行能力的，对于吉大这个烂就业环境来说，知道秋招不在秋天，暑期不在夏天，能按时在大三下参加报名暑期实习，就已经算高瞻远瞩了。倘若暑期前还能再刷一段，在泥吉算的上就业领域大神。

所以我们必须以普通人的视角，阐述一段实现难度不高的就业标准时间节点：

1. 大三下/研二下开始 **暑期实习**：三月初黄金期，延续到六月末基本结束。各大企业投放包含转正的实习机会。

2. 大三暑假/大四上 **秋招**： 八月初到十二月————秋招补录。

3. 大四寒假/大四下 **春招**：二月底到六月，基本为秋招和考研失败者做最后兜底，捡漏为主，难度极大，是统一校招的最后机会。

关于距离重要节点的剩余时间，我们去做最有意义的事情。

### 3.2 简历准备须知
第一段实习来说，简历往往需要两个能打的项目，一个可以看懂的编程语言，一系列技术栈的八股问题。当然对于大厂还有隐性的算法问题，要能刷出hot100的大部分原题。

对于简历的实质性准备，要注意的点太多了。

#### **简历内容性价比**
有实习问实习，没实习问项目，项目太烂大街，或者实在不匹配，就只能问八股拷打技术栈广度深度去看你有没有自己的思考。所以我们第一段实习的最大方向就是项目和八股。。特殊内容：竞赛，开源经历，个人技术博客，有含金量的可以写一写，属于边缘加分项，极优秀的可以另开辟一条道路去求职了，但脱离混子求职掌握的范畴了。学校奖学金，绩点排名，英语水平，校级比赛.....这一类完全无人在意，属于实在没招了，你可以去写一写，可以用于混简历。个人性格，学习课程，学校实验大作业。非要写这种东西上去，面试官基本都会觉得你连一页简历都凑不齐，实在拿不出任何例证了，基本都是减分项。

#### **简历撰写**
善用AI包装，但是不要只用AI。很多东西用ai包装在你的简历上实际上是没有信息量的，要想清楚面试官想看见什么，一切要站在通过简历筛选通过面试考察的角度上。这里就不详细讲了。前面两个视频里可以阐述的很清楚。


### 3.3 投递准备须知
一般的投递渠道就是boss + 官网，第一次找实习投递往往都要经历一次挫败，前面视频说的太全了，这里依旧只直接说一下现状。

3 ~ 5月，8 ~ 10月，这俩阶段一定是海量招实习的阶段。这两个时间段往往一天boss投满150次，能有一个约面，对于你这个简历来说就是成功的。一周投满6天拿4个约面，一周4面你还有什么好怕的。

另外推荐一下脚本海投，因为简历投递是一件极度费心费力的事情，往往投完也不想学什么东西了。boss海投助手 + 牛客网申助手，都是轻量级的浏览器插件。

我当时每天就是早上10点准时点开插件，boss免打扰，下午2点半定个闹钟依次回简历，有电话接电话，没电话就在鼎新学自己的。


### 3.4 面试准备须知
实习的话一般大厂是两轮技术，部分厂有HR面。小厂实习可能就一轮技术就是了。

秋招的话一般是三轮技术面+HR面。小厂秋招不太清楚，没了解过，应该也是至少两轮技术。

每次面完快的话可能十分钟就有结果，慢的话可能三四天，四五天，甚至一周。和视频讲述一致，一定不要急，面试就是随堂小测。
